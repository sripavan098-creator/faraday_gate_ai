# Faraday Gate


**Your agents. Your code. No leaks.**


Faraday Gate is a CLI-native, zero-egress AI agent firewall for Snapdragon-powered HP PCs.


It protects developers using AI coding agents from leaking secrets, private code, customer data, and proprietary logic — and from prompt-injection attacks hidden inside repository content.


This repository is currently in Step 1: project foundation.
